<!-- Objetivos -->
O objetivo do projeto Quiz dos Super Titãs é a produção de um site que terá um quiz educativo, para <strong>ajudar as crianças e professores em suas aulas</strong>, afim de aprimorar o aprendizado dos alunos atravéz da <strong>gamificação</strong>, com o objetivo específico sendo a implementação dos requisitos levantados para o projeto, como a possibilidade de se fazer um <strong>login com senha</strong>, <strong>cadastro no site</strong>, <strong>o salavamento do progresso</strong> do estudante no quiz, dentre outros requisitos.

<h3><strong>Requisitos do projeto: Funcionais, Não Funcionais e Regras de Negócio</strong></h3>
<!-- Requisitos Funcionais -->
<h4><strong>Requisitos Funcionais</strong></h4>
<p>Os Requisitos Funcionais são tudo o que o sistema deverá fazer, incluindo funcionalidades, ações e operações. Alguns dos Requisitos Funcionais do projeto estão logo abaixo.</p>
RF1: O sistema deve permitir que os usuários façam a leitura, inserção, alteração e exclusão de dados em seu cadastro, desde que tenha feito login no site<br>
RF3: O sistema deve permitir que usuários façam login com senha<br>
RF6: O sistema deve salvar o desempenho e progressão do usuário dentro do quiz<br>
RF7: O sistema deve permitir os usuários a acessar e fazer o quiz a qualquer momento, desde que tenha feito login no site

<!-- Requisitos Não Funcionais -->
<h4><strong>Requisitos Não Funcionais</strong></h4>
<p>Os Requisitos Não Funcionais são limitações impostas ao sistema. Seguem abaixo alguns exemplos dos Requisitos Não Funcionais do projeto.</p>
RNF1: O sistema deve ser seguro para os usuários, onde os usuários devem criar login e senha de acesso<br>
RNF2: O sistema não deve permitir que usuários leiam, insiram, alterem e excluam de dados no cadastro de outros usuários<br>
RNF3: O sistema deve manter as informações dos usuários, sensíveis ou não, seguras de invasores utilizando criptografia<br>
RNF7: O sistema deve ter uma interface agradável e intuitiva

<!-- Regras de Negócio -->
<h4><strong>Regras de negócio</strong></h4>
<p>Regras de Negócio são normas da própria empresa, que definem comportamentos operacionais, podendo, ou não, gerar limitações e Requisitos Não Funcionais. Os exemplos de Regras de Negócio estão abaixo.</p>
RN1: O usuário deve criar uma senha forte para seu login<br>
RN4: Deve-se haver o acesso de usuário e de adm<br>
RN6: O sistema deve permitir que somente a administração visualize, insira, exclua e altere dados no cadastro de todos os usuários cadastrados no sistema
